# 🧠 Classificação do Nível de Atividade Física com Machine Learning

Este projeto apresenta um pipeline completo de mineração de dados e aprendizado de máquina para classificação do nível de atividade física de indivíduos utilizando o software Weka.

O trabalho foi desenvolvido como atividade acadêmica da disciplina de Inteligência Artificial / Metodologia para Computação.

---

# 🎯 Objetivo

Classificar indivíduos em diferentes níveis de atividade física com base em características relacionadas ao estilo de vida, hábitos diários e indicadores de saúde.

As classes utilizadas foram:

- Sedentario
- Moderadamente_Ativo
- Ativo
